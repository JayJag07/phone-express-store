## ✨ Features

- **Animated carousel** — auto-plays every 5 seconds with smooth slide transitions
- **Full navigation** — dot indicators, arrow buttons, keyboard arrow keys, and touch/swipe support
- **Progress bar** — real-time fill animation showing time until next slide
- **Mobile-first design** — fully responsive with hamburger menu for mobile
- **Animated background** — floating orb effects and scan-line animation
- **Image fallback** — displays styled placeholder if product image fails to load
- **Pause on hover** — carousel pauses when the user hovers over the content
- **Accessibility** — ARIA labels on all interactive controls

---

## 🛠️ Built With

- HTML5 — semantic structure
- CSS3 — custom animations, keyframes, CSS variables, flexbox
- JavaScript (ES6+) — carousel logic, touch events, IntersectionObserver, keyboard navigation
